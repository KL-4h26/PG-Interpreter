# **Язык программирования - PG**
![icon](https://i.ibb.co/9H1985bn/lv-0-20260809150558.png)

PG это интерпретируемый язык программирования, написанный на Python, мой первый интерпритатор вышедший за рамки статичных команд и отсутствием нормальных конструкций. Имеет втроенные функции и структуры (конструкции), поддерживает создание переменных и функций, разные типы данных и операции с ними. Подробнее обо всем разберем ниже.

## - Переменные
Давайте определим несколько переменных используя наш язык программирования:
```
// Базовые значения
name := "KL"
num := 5
float_num := 5.0
boolean_value := True

// Арифметика и булевые операции
arifmetic_num := num + 2
boolean_value := name == "KL"

// Подстановка значений в строки
format_string := $"My name is >name<"  // $ указывает что подстановка доступна
```
Как вы можете видеть, тут демонстрируюется возможность определения переменных и типы данных (В будущем я пополню список доступных типов).

## - Функции
Функции, принимают аргументы, выполняют с ними различные операции, могут вернуть результат. Стоит отметить что каждая функция возвращает либо 0 либо другие данные, обычно 0 обозначает пустой ответ

### > show()
```
show("Hello, World!")
```
Функция вывода, принимает любое количество аргументов любых типов.  
Возвращаемое значение: 0 (Пусто)

### > input()
```
input("Hello, World!")
```
Функция ввода, принимает один опциональный аргумент.  
Возвращаемое значение: (текст введенный пользователем)

### > stop()
```
stop()
```
Функция остановки программы, не принимает аргументов  
Возвращаемое значение: 0 (Пусто)

### > lenght()
```
lenght("DDDDD")
```
Функция подсчета, принимает один аргумент  
Возвращаемое значение: (колличество элементов/символов)

### > type()
```
type(123)
```
Функция получения типа данных, принимает один аргумент  
Возвращаемое значение: (строка, обозначает тип данных)

### > tostr(), toint(), tofloat(), tobool()

```
tostr(1)
toint("2")
tofloat(6)
tobool("False")  // True ;)
```
Функции приведения типов, принимают один аргумент  
Возвращаемое значение: (те же данные с новым типом)

```

}

```
