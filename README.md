## - Установка
Для начала установим наш интерпритатор и запустим первую программу  
`git clone https://github.com/KL-4h26/PG-Interpreter`

Установив репозиторий зайдем в него и создадим виртуальное окружение  
`python -m venv venv`

Активируем его  
`source venv/bin/activate`  
или если вы на Windows:  
`source venv\Scripts\activate`

Скачиваем зависимости из requirements.txt  
`pip install -r requirements.txt`

И запускаем нашу первую программу на PG:  
`python penguin/lang.py -f script.pg`  
При желании можно собрать в исполняемый файл через pyinsaller


## - Переменные
Давайте определим несколько переменных используя наш язык программирования:
```
// Базовые значения
name := "KL"
num := 5
float_num := 5.0
boolean_value := True

// Арифметика и булевые операции
arifmetic_num := num + 2  // Можно использовать += 2
boolean_value := name == "KL"

// Подстановка значений в строки
format_string := $"My name is >name<"  // $ указывает что подстановка доступна
```
Как вы можете видеть, тут демонстрируюется возможность определения переменных и типы данных (В будущем я пополню список доступных типов).

## - Функции
Функции, принимают аргументы, выполняют с ними различные операции, могут вернуть результат. Стоит отметить что каждая функция возвращает либо 0 либо другие данные, обычно 0 обозначает пустой ответ

### > show()
```
show("Hello, World!")
```
Функция вывода, принимает любое количество аргументов любых типов.  
Возвращаемое значение: 0 (Пусто)

### > input()
```
input("Hello, World!")
```
Функция ввода, принимает один опциональный аргумент.  
Возвращаемое значение: (текст введенный пользователем)

### > stop()
```
stop()
```
Функция остановки программы, не принимает аргументов  
Возвращаемое значение: 0 (Пусто)

### > lenght()
```
lenght("DDDDD")
```
Функция подсчета, принимает один аргумент  
Возвращаемое значение: (колличество элементов/символов)

### > type()
```
type(123)
```
Функция получения типа данных, принимает один аргумент  
Возвращаемое значение: (строка, обозначает тип данных)

### > tostr(), toint(), tofloat(), tobool()

```
tostr(1)
toint("2")
tofloat(6)
tobool("False")  // True ;)
```
Функции приведения типов, принимают один аргумент  
Возвращаемое значение: (те же данные с новым типом)

### > python()

```
python("print('Hello, There!')")
```
Функция исполнения python кода, принимает один аргумент  
Дает простор для добавления python библиотек в PG
Возвращаемое значение: 0 (ничего)

## - Конструкции
Конструкции разнообразием не блещут, их я сделал пока.. всего два

### >> if ()
```
if (False){
    show("Я никогда не выполнюсь")
} elif(False){
    show("Увы я тоже")
} else() {
    show("Наконец")
}
```
if и elif всегда принимают один аргумент - условие (или просто булевое значени)
else же просто выполняется в конце условия, если все предыдущие не выполнились

### >> while
```
while (True){
    show("Бесконечный вывод")
}
```
Принимает условие, выполняет код пока условие истинно

## - Собственные функции
```
function greeting(name){
    show($"Hello, >name<!")
}
greeting("KL")
```
Вы всегда можете написать собственную функцию с любой логикой, просто напишите
`return value`
если хотите вернуть значение из функции
